# Carpeta app

Esta carpeta se conserva porque forma parte de la estructura original del proyecto y contiene los archivos de rutas/template (`_layout.tsx`, `(tabs)/index.tsx`, etc.).

La aplicación principal actualmente se registra desde `index.js` y monta `App.js`. La lógica grande fue separada en `src/app`, `src/screens` y `components` para que los archivos de entrada permanezcan pequeños y fáciles de leer.
